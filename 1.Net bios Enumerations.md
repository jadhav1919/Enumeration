# NetBIOS Enumeration 
### Introduction

NetBIOS (Network Basic Input Output System) is a protocol mainly used in Windows systems for communication inside a Local Area Network (LAN).

It helps computers:

- Identify each other using names
- Share files and printers
- Communicate over a network
- Access shared resources
Instead of remembering IP addresses, systems can communicate using names like: WINDOWS11, SERVER01, OFFICE-PC
  
**NetBIOS** = Network Basic Input/Output System

- NetBIOS name is a unique **16 ASCII character** string
- **15 characters** = device name
- **16th character** = reserved for service type

### Why NetBIOS Enumeration is Important

In cybersecurity, attackers first perform: Information Gathering

before launching attacks.
NetBIOS enumeration helps attackers collect useful information about a target system or network.
Sometimes this information can be obtained without authentication.

### NetBIOS Enumeration Information

| Information / Code | Type | Description | Information Obtained |
|---|---|---|---|
| Hostname | `<00>` UNIQUE | Identifies the target computer | Computer name |
| Domain / Workgroup | `<00>` GROUP | Identifies the network group | Domain or workgroup name |
| Messenger Service (Host) | `<03>` UNIQUE | Messenger service running for the computer | Host messaging service |
| Messenger Service (User) | `<03>` UNIQUE | Messenger service for logged-in user | Active username |
| Server Service | `<20>` UNIQUE | SMB/File Sharing service enabled | Shared folders and SMB access |
| Master Browser | `<1D>` GROUP | Master browser for subnet | Network browsing information |
| Domain Controller | `<1B>` UNIQUE | Primary Domain Controller (PDC) | Main domain controller |
| Browser Elections | `<1E>` GROUP | Browser election service | Network browser election details |
| Shared Folders | SMB Share | Accessible network shares | Shared directories |
| Logged-in Users | User Info | Information about active users | User accounts |
| Running Services | Service Info | Services running on the target | SMB, Printer Sharing, etc. |
| MAC Address | Physical Address | Hardware network address | Device MAC address |

### NetBIOS Ports

NetBIOS (Network Basic Input/Output System) is a communication protocol used mainly in Windows systems for:

- File sharing
- Printer sharing
- Network communication
- Device identification

NetBIOS works using three important ports:

| Port | Protocol | Service Name | Main Function |
|---|---|---|---|
| **137** | UDP | NetBIOS Name Service (NBNS) | Name resolution and device discovery |
| **138** | UDP | NetBIOS Datagram Service | Broadcast communication and messaging |
| **139** | TCP | NetBIOS Session Service | SMB sessions, file sharing, and remote access |
